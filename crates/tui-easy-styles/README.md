# tui-easy-styles

`anstyle` → `ratatui` style conversion, plus a shared `HyperlinkTarget` type,
for [ratatui](https://ratatui.rs) apps.

Part of [tui-easy](https://github.com/nixpt/tui-easy); most users depend on the
`tui-easy` umbrella crate with its `styles` feature instead of this crate
directly.

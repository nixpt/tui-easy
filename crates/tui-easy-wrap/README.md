# tui-easy-wrap

Word-wrap helpers over `ratatui` `Line` / `Span` values, built on
[`textwrap`](https://crates.io/crates/textwrap).

Part of [tui-easy](https://github.com/nixpt/tui-easy); most users depend on the
`tui-easy` umbrella crate with its `wrap` feature instead of this crate
directly.
